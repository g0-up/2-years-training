Chặng 1 · Tháng 1–8 · Học chung

Cơ bản

Nền tảng tư duy lập trình, công cụ làm việc, và hiểu cách một hệ thống web vận hành từ đầu đến cuối.

1.1Công cụ làm việc

Học ngay tháng đầu, dùng xuyên suốt.

  • Git & version control: commit, branch, merge, remote, GitHub/GitLab
  • Linux & command line: điều hướng, quyền file, process, grep/find, ssh
  • AI trong học tập: dùng AI để giải thích code, sinh bài tập, tự review bài làm, kèm nguyên tắc: hiểu trước khi dùng, không copy mù
  • IDE & môi trường: cài đặt, shortcut, debugger cơ bản

1.2Nền tảng Internet & thuật ngữ ngành

  • Cách web hoạt động: client–server, HTTP/HTTPS, request/response, DNS
  • JSON, REST API là gì
  • Các thuật ngữ trong ngành IT: dev/QA/BA/PM, môi trường dev/staging/prod, bug/feature, sprint...

1.3Tư duy lập trình

  • Data structures: array, list, map, stack, queue, tree cơ bản
  • Algorithms: sort, search, đệ quy, độ phức tạp Big-O
  • Debugging: dùng debugger, đọc stack trace, đọc log, rèn như thói quen trong mọi bài tập

1.4Ngôn ngữ & dữ liệu

  • SQL: CRUD, JOIN, GROUP BY, thiết kế bảng cơ bản
  • Golang: cú pháp, struct, interface, goroutine cơ bản, viết CLI tool nhỏ
  • HTML, CSS, JS: dựng trang tĩnh, DOM, fetch API

1.5Mobile nhập môn

  • Flutter cơ bản: widget, layout, state đơn giản, ở mức làm quen, chưa đi sâu

Đầu ra chặng 1

Hoàn thành chặng Cơ bản khi

  • Dùng Git + terminal thành thạo trong mọi bài tập
  • Tự build 1 ứng dụng nhỏ: Golang API đơn giản + trang web tĩnh gọi API đó
  • Giải thích được luồng đi của 1 HTTP request từ browser đến database và quay lại

Chặng 2 · Tháng 9–17 · 1 hướng chính + 1 hướng phụ

Nâng cao

Đi sâu một hướng chuyên môn, biết viết code có kiểm thử, an toàn, đóng gói và sẵn sàng triển khai.

Học viên chọn 1 hướng chính (học đầy đủ) và 1 hướng phụ (học phần cốt lõi).

2.1Kiến thức chung bắt buộc (mọi hướng đều học)

  • Phân tích và thiết kế hệ thống: phân rã chức năng, vẽ sơ đồ (use case, sequence, ERD), thiết kế module
  • Testing: unit test, integration test, mocking; bắt buộc trong mọi bài tập lớn từ đây về sau
  • Database nâng cao: index, transaction, N+1 query, tối ưu query, thiết kế schema cho bài toán thật
  • API design & bảo mật cơ bản: REST chuẩn, authentication/authorization (session, JWT, OAuth2), OWASP Top 10
  • Docker & containerization: Dockerfile, docker-compose, đóng gói ứng dụng của chính mình
  • Clean code & design patterns: gắn trực tiếp vào bài tập chuyên môn, kèm code review chéo giữa học viên
  • AI trong phát triển phần mềm: AI coding assistant (sinh code, refactor, viết test, review), giới hạn và rủi ro khi dùng AI trong dự án thật
  • Mức khái niệm + 1 lab nhỏ: caching với Redis, message queue
2.2 · Hướng Backend
  • Golang nâng cao: context, concurrency pattern, error handling
  • GORM / sqlx, migration, repository pattern
  • Xây dựng REST API hoàn chỉnh: middleware, validation, logging, config
  • Cấu trúc project chuẩn, phân tầng (handler – service – repository)
2.3 · Hướng Frontend
  • ReactJS: component, hooks, state management
  • Vite, cấu trúc project, environment config
  • TailwindCSS, responsive design
  • Gọi API, xử lý auth phía client, error/loading state
2.4 · Hướng Mobile
  • Flutter nâng cao: navigation, async, gọi API
  • BLoC pattern, quản lý state
  • Material Design, responsive cho nhiều kích thước màn hình
  • Build & cài app lên thiết bị thật

Đầu ra chặng 2

Hoàn thành chặng Nâng cao khi

  • Hoàn thành 1 dự án cá nhân theo hướng chính: có test, có Docker, có tài liệu API/thiết kế
  • Vượt qua code review theo checklist clean code
  • Giải thích được các quyết định thiết kế của chính mình: vì sao chọn cấu trúc này, đánh index ở đâu, auth hoạt động thế nào

Chặng 3 · Tháng 18–24 · Dự án team

Thực hành

Làm dự án theo team như môi trường thật, từ lấy requirements đến vận hành sau khi lên production.

Dự án làm theo team 3–5 người, mỗi team có đủ vai trò Backend / Frontend / Mobile theo hướng từng người đã chọn.

3.1Requirements & tài liệu

  • Cách lấy requirements từ người dùng: phỏng vấn, đặt câu hỏi, xác nhận lại
  • Phân tích requirements: tách user story, xác định scope, ưu tiên MoSCoW
  • Xây dựng tài liệu dự án: SRS/spec rút gọn, thiết kế hệ thống, API docs

3.2Quy trình làm việc nhóm

  • Agile/Scrum cơ bản: sprint, daily, retro, estimate effort
  • Quản lý task trên Jira (hoặc tương đương)
  • Git workflow thực chiến: branching strategy, pull request, resolve conflict, code review bắt buộc trước khi merge

3.3Xây dựng sản phẩm

  • Xây dựng ứng dụng backend, frontend, mobile theo thiết kế đã duyệt
  • Viết test song song với code, duy trì coverage tối thiểu theo quy định team

3.4Triển khai & vận hành

  • Triển khai hệ thống lên môi trường internet (VPS/cloud)
  • CI/CD: pipeline tự động build – test – deploy (GitHub Actions / GitLab CI)
  • Vận hành sau deploy: logging, monitoring cơ bản, xử lý sự cố, fix bug trên môi trường thật
  • Quy trình release: versioning, rollback khi có lỗi

3.5Trình bày sản phẩm

  • Demo & thuyết trình trước “khách hàng” (mentor đóng vai), milestone bắt buộc cuối mỗi dự án
  • Viết tài liệu bàn giao

Đầu ra chặng 3 · Tốt nghiệp

Tốt nghiệp khi có

  • 1 sản phẩm hoàn chỉnh chạy trên internet, có CI/CD, có monitoring
  • Bộ tài liệu dự án đầy đủ: requirements, thiết kế, API docs, tài liệu bàn giao
  • Lịch sử Git thể hiện làm việc nhóm thật: PR, review, resolve conflict
  • Buổi demo cuối khóa trước hội đồng
